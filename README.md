# Vasicek vs. CIR Interest Rate Models

A Python-based comparison of the Vasicek and Cox–Ingersoll–Ross (CIR) short-rate models, focusing on numerical simulation, volatility stress testing and zero-coupon bond valuation.

## Methodology

- Euler–Maruyama simulation
- Exact Vasicek simulation benchmark
- Numerical convergence analysis
- CIR Feller-condition analysis
- Terminal-rate distribution and lower-tail analysis
- Monte Carlo bond valuation
- Volatility sensitivity analysis

## Repository contents

- `Vasicek-CIR Models.ipynb` — full implementation, analysis and results

## Libraries

Python · NumPy · pandas · Matplotlib · Jupyter Notebook
